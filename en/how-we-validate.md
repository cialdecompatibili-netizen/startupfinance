<p class="hub-lead">The loop is simple: talent brings ideas, we validate them, investors follow only the ones that hold up.</p>

## The stages
<ol class="hub-steps">
<li><strong>Problem</strong>: we talk to real people to see if the problem exists.</li>
<li><strong>Minimum solution</strong>: we build the smallest version that can be tested.</li>
<li><strong>First customers</strong>: we measure whether anyone really uses or pays.</li>
<li><strong>Decision</strong>: continue, change direction or stop.</li>
</ol>

## Transparency
For each startup we publish the status and verified results, with the source. No made-up numbers.
